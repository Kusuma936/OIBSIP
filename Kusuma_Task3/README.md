# ATM Interface

## Task 3 - Oasis Infobyte Java Development Internship

This project is a simple console-based ATM Interface developed using Java.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Display updated balance
- Exit the ATM system

## Technologies Used

- Java
- Scanner class
- Conditional statements
- Switch statement
- Methods

## How to Run

1. Compile the program:
   `javac ATMInterface.java`

2. Run the program:
   `java ATMInterface`
