# Number Guessing Game

## Task 2 - Oasis Infobyte Java Development Internship

This project is a console-based Number Guessing Game developed using Java.

## Features

- User can select a difficulty level.
- A random number is generated by the program.
- User gets a limited number of attempts.
- The program gives hints such as higher or lower.
- Displays the number of attempts remaining.
- Shows the correct number when the game ends.
- Allows the user to play again.
- Keeps track of the best score.

## Technologies Used

- Java
- Java Scanner
- Random Number Generation

## How to Run

1. Download or clone this repository.
2. Open `NumberGuessingGame.java` in a Java IDE.
3. Compile the program.
4. Run the program.
5. Select the difficulty level and start guessing.
